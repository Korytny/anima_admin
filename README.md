# Проект: Admin Dashboard для управления пайплайном создания видеороликов

Создай профессиональную, функциональную админку для управления полным циклом производства видеороликов. Это desktop-only приложение для команды видеопродакшена с тёмной премиальной темой. Система должна позволять управлять контент-планом, сценами роликов, AI-агентами и настройками в едином интерфейсе.

## 🛠 Технологии и стек
- React 18
- shadcn/ui компоненты (кастомизированные под тёмную тему)
- Tailwind CSS v4
- TanStack Table для продвинутых таблиц
- Lucide React для иконок
- Framer Motion для анимаций
- Radix UI для доступных компонентов

## 🎯 Особые требования

- **Desktop only** — оптимизировано для экранов 1440px+
- **Keyboard shortcuts:** Cmd+K (поиск), N (новая запись), Esc (закрыть), Cmd+S (сохранить)
- **Accessibility:** ARIA-атрибуты, keyboard navigation, focus states (фиолетовая обводка 2px)
- **Производительность:** виртуализация таблиц, lazy-loading изображений
- **Сохранение состояния:** настройки видимости столбцов, сортировки, фильтров в localStorage
- **Empty states:** красивые заглушки с иллюстрациями когда нет данных
- **Toast-уведомления:** в правом верхнем углу при действиях
- **Подтверждения:** модальные окна для опасных действий (удаление)

## 💫 Общее настроение

Профессиональный, функциональный инструмент для ежедневной работы. Как Figma или Linear — плотный, быстрый, отзывчивый. Тёмная премиальная тема с фиолетовыми и золотыми акцентами создаёт ощущение технологичного творческого инструмента. Никаких лишних анимаций — только там, где они помогают UX.

## 📸 Медиа и контент

- Используй placeholder-изображения для превью
- Видео-заглушки с постерами
- Для иконок агентов — стилизованные аватары с инициалами
- Все статусы с понятными цветами:
  - Draft — серый
  - In Progress — фиолетовый (с пульсацией)
  - Review — золотой
  - Approved — зелёный
  - Published — синий
  - Paid — золотой с свечением

Начни с создания главной страницы (Контент-план) с полной таблицей, боковой панелью, верхней панелью инструментов и быстрой карточкой справа. Затем последовательно добавь остальные страницы.
